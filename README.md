# DateDrop 💌

DateDrop is a playful full-stack web application for sending someone an interactive date invitation.

The recipient follows a fun step-by-step experience to accept or decline the invitation, choose a date type, cuisine, date and time, and receive a playful confirmation.

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS

### Backend

- Node.js
- Express
- TypeScript
- Zod

### Database

- SQLite
